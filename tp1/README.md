# Elias Berrada

## Project Overview

This project corresponds to the first assignment of the Operating Systems course (2026). Its purpose is to prepare a Linux working environment and execute a Bash script that gathers essential information about the system. The work was completed using a cloud-based platform such as Killercoda or Google Colab.

The script `sys_info.sh` displays the following details:

1. The operating system name and the current Linux kernel version.
2. The username of the active user session.
3. The location of the current working directory.
